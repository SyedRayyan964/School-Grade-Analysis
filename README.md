# School Grade Analysis System

## Project Description
A Python-based School Grade Analysis System developed using Pandas for analyzing student academic performance.

This project processes student marks, calculates totals and percentages, assigns grades, determines pass/fail status, and generates structured analytical reports using DataFrames.

The goal of this project is to practice data analysis, dataframe manipulation, logical problem solving, and reporting techniques commonly used in data science and analytics workflows.

---

## Features

- Student marks management
- Total marks calculation
- Percentage calculation
- Pass/Fail status analysis
- Grade assignment system
- DataFrame-based reporting
- Multi-student performance analysis
- Subject-wise marks handling
- Automated report generation
- Structured tabular output
